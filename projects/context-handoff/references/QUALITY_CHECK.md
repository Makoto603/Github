# Quality Check

Before finalizing a handoff, verify:

## General
- [ ] Project objective is understandable.
- [ ] Current state is explicit.
- [ ] Latest specification is unambiguous.
- [ ] Superseded values are not mixed into CURRENT.
- [ ] Next action is concrete.
- [ ] Important constraints survived compression.
- [ ] Uncertainty is labeled instead of guessed.

## Codex
- [ ] AGENTS.md contains stable rules, not a project diary.
- [ ] CURRENT.md contains volatile state.
- [ ] Test/build/run commands are discoverable.
- [ ] Important files are identified.
- [ ] Data-loss risks are documented.
- [ ] Active bugs are in KNOWN_ISSUES.
- [ ] A fresh session can continue without the old conversation.

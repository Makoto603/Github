# Handoff Schema

## WEB files
- handoff/CURRENT.md
- handoff/TODO.md
- handoff/HISTORY.md
- handoff/START_PROMPT.md

## CODEX files
- handoff/CURRENT.md
- handoff/ARCHITECTURE.md
- handoff/KNOWN_ISSUES.md
- handoff/TODO.md
- handoff/HISTORY.md
- handoff/CONFLICTS.md when needed
- handoff/START_PROMPT.md

CURRENT is the current authoritative operational state.
HISTORY is historical/reference only.
START_PROMPT tells a fresh session which files are authoritative and which task resumes first.
